- 지원 작물과 생성된 제어 명령을 검증하는 2단계 Guardrail 구현
- 장치, 동작 및 물리적 허용 범위를 벗어난 제어 명령 차단

`Python` `FastAPI` `LangGraph` `RAG` `Gemini API`

- Python과 FastAPI 기반 백엔드 API 구현
